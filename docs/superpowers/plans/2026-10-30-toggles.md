# Toggles (toggle sneak + auto-walk) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An AMML mod `alaydriem-toggles` that gives Minecraft Bedrock 26.60 a toggle sneak and an auto-walk, with all key work done through the mod manager.

**Architecture:** The mod manager (`../modmanager-amml`) gets two new mod APIs, "watch keys" and "send key". It also gets an internal fake-key book that holds back real key-ups, releases fake keys on focus loss, panel open, disable, unregister and world exit, and passes fake keys to the game's original `onKeyDown` / `onKeyUp` on the manager's tick. The toggles mod is a Zoom-shaped workspace. `toggles-core` holds all rules and has no unsafe code. `toggles-amml` reads menu and death state each tick and turns manager events into `send_key` calls.

**Tech Stack:** Rust 2024, AMML SDK (`../amml/sdk/sdk`), `amml-game`, `amm-client` / `amm-core` / `amm-abi` (`../modmanager-amml`), mise, cargo-nextest, cbindgen (manager header).

**Spec:** `docs/superpowers/specs/2026-10-30-toggles-design.md`

## Global Constraints

- Game build: 26.60 only, BuildId `6ad79ee4-17d51891a1119914`.
- Keyboard only. No sprint toggle. No on-screen indicator.
- No new AMML recipes (no movement-input recipes, no option lookup recipe).
- The toggles mod has **no keyboard hook**. All key input and output goes through the manager.
- Defaults: sneak toggle `F3+Shift`, auto-walk toggle `F3+W`, cancel keys `W`, `S`, game Sneak key `Shift`, game Forward key `W`, reset on menu `true`, reset on death `true`, enable sneak `true`, enable auto-walk `true`.
- Mod id `alaydriem-toggles`. DLL `alaydriem_toggles.dll`.
- **No commits** (operator rule). Every "Checkpoint" step means: run the named mise tasks, they must pass, and the work stays uncommitted for operator review.
- Build and test only through `mise run <task>` in each repo. Do not pipe build or test output through `grep`, `tail` or `head`.
- Never weaken a lint or a check. Follow each repo's `CLAUDE.md`.
- `../modmanager-amml` has uncommitted work from another agent (F3 chord support, ABI 2.0 capture stream). Do not revert, reformat or move it. Touch only the lines this plan names.
- In plans and specs, write issue numbers with a space after `#`.

## Review Focus

1. **Cancel while the cancel key is the faked key.** The player presses real W during auto-walk and keeps holding it. Auto-walk must hand W over to the real key and the player keeps walking. W must not be released under their finger. Test: Task 2 `send_key_up_while_real_key_down_sends_nothing`.
2. **Game key setting changed while a toggle is on.** The old key must be released, not left stuck. Test: Task 6 `game_key_change_releases_old_key`.
3. **The toggle chord's own key reaching the toggles mod as a cancel.** F3+W must not cancel the auto-walk it starts. Test: Task 2 `keybind_press_is_not_sent_to_watchers`.
4. **An older manager without the new functions.** The toggles mod must log once and stay off, with no crash. Test: Task 4 `send_key_on_minor_0_table_is_unsupported`, Task 7 `link_without_send_key_stays_off`.
5. **Key repeat.** A held cancel key sends repeat downs. Only the first down counts, and repeats of the faked key must not stack. Test: Task 6 `repeat_key_down_is_not_a_cancel`, Task 2 `send_key_down_twice_queues_one_op`.

**Interfaces:**
- Produces:
  - `pub struct FakeKeyOp { pub vk: u32, pub down: bool }` (`Copy`, `Eq`)
  - `FakeKeys::hold(&mut self, index: ModIndex, vk: u32) -> bool` (true when newly held), `FakeKeys::release(&mut self, index: ModIndex, vk: u32) -> bool`, `FakeKeys::release_mod(&mut self, index: ModIndex) -> ModMask` (which mods lost keys), `FakeKeys::release_all(&mut self) -> ModMask`, `FakeKeys::is_held(&self, vk: u32) -> bool`, `FakeKeys::take_ops(&mut self, out: &mut Vec<FakeKeyOp>)`
  - `KeyWatch::set(&mut self, index: ModIndex, vks: &[u32])`, `KeyWatch::forget(&mut self, index: ModIndex)`, `KeyWatch::watchers(&self, vk: u32) -> ModMask`
  - `ModEvent::FakeKeysReleased`
  - `ManagerService::watch_keys(&mut self, index: ModIndex, vks: &[u32]) -> Result<(), ManagerError>`
  - `ManagerService::send_key(&mut self, index: ModIndex, vk: u32, down: bool) -> Result<(), ManagerError>`
  - `ManagerService::take_fake_keys(&mut self, out: &mut Vec<FakeKeyOp>)`
  - `KeyWatch::MAX_KEYS = 32`

Rules:
- `watch_keys` and `send_key` need a `claim` on `Input` in the mod's descriptor, else `NotPermitted`. A `vk >= 256`, or more than `MAX_KEYS` keys, is `InvalidArgument`. `watch_keys` replaces the mod's set, and an empty slice clears it.
- `send_key` is `NotPermitted` while the panel is open. A key-down is also `NotPermitted` while **any** other mod holds an active `Input` lease, Shared or Exclusive (operator rule: defer to DejaVu and other mods with input control). When an `Input` lease becomes active for a mod (grant, preempt or resume), every other mod's fake keys are released, and those mods get `FakeKeysReleased`. Tests: `send_key_while_other_mod_holds_input_is_not_permitted`, `input_lease_granted_to_other_releases_fake_keys`, `send_key_up_allowed_while_other_holds_input`.
- `send_key(down = true)` on a key the mod already holds queues nothing. `send_key(down = false)` on a key it does not hold queues nothing.
- `send_key(down = false)` while the **real** key is down (`key_state.is_down(vk)`) drops the hold and queues nothing. The real key-up releases it later.
- In `route`: a real `Key { down: false }` whose `vk` is held by `FakeKeys` gets `consume_from_game = true`.
- In `deliver`: a `Key` event with `consume_from_game == false` and `to_panel == false` goes as `ModEvent::Key` to `watchers(vk)`, except mods already in `raw_targets`.
- `FocusLost`, the panel changing from closed to open, and world left call `release_all`. `set_enabled(index, false)` and `unregister(index)` call `release_mod` and `KeyWatch::forget`. Each mod that lost a key gets `ModEvent::FakeKeysReleased`. The released keys are queued as `FakeKeyOp { down: false }`, except keys whose real key is down.
